物性与反应计算

查询物性与水蒸汽性质，计算气液平衡和反应热；接入 Cantera，研究支持机理下的气相化学平衡与反应动力学。

物性查询 · 相平衡 · 反应计算

工艺流程模拟

接入 DWSIM 建立稳态流程，连接反应、闪蒸、精馏与循环单元；调整操作条件，比较物流组成、产量和冷热负荷。

稳态流程 · 参数调整 · 多工况比较

设备与能量估算

估算换热器面积、精馏理论级数、管路压降与泵功率；通过显热物流夹点分析，计算最小冷热公用工程需求。

换热与精馏 · 管路计算 · 能耗分析

工艺图纸与厂区三维

生成 PFD 流程草图和设备数据表；用 Blender 表达设备、管道、管廊与建筑，导出三维模型及渲染图。

流程图 · 设备数据表 · 三维演示

经济评价与方案比较

结合设备、原料及能源价格估算成本，计算税前净现值与回收期，分析收入和成本变化对方案经济性的影响。

成本估算 · 净现值 · 敏感性分析

技术研究与报告生成

检索论文与化学数据，读取技术文献、分析实验表格；生成计算报告和演示文稿，汇总图纸与模型成果。

文献检索 · 数据拟合 · 文档生成

GOOD TO KNOW

开始之前，
你可能想了解。

这是在线计算网站吗？+

这里是产品介绍、案例展示与下载网站。安装 ChemELLM 后，在 Codex 中用对话调用本机工程工具完成计算、模拟和成果生成。模型服务、在线检索及软件安装需要相应的网络连接。

适合从哪些化工任务开始？+

可以从水蒸汽性质、闪蒸分离、换热面积、管路压降或精馏捷算开始，也可以研究支持机理的气相反应、比较 DWSIM 稳态工况，或生成流程图和厂区三维演示。提供处理量、组成、温压与目标，有助于选择合适模型。

安装包包含哪些专业软件？+

安装器准备基础 Python 计算依赖。DWSIM、Blender、FreeCAD、QElectroTech、LibreOffice 和 Cantera 等按需单独安装，不随 ZIP 分发。DWSIM 接入目前面向 Windows 稳态仿真，复杂模型需要另行配置与验证。

流程仿真能做什么？+

支持建模前检查、稳态求解、独立守恒校核、最多 50 个工况的串行比较和工程对象联动，支持原生布局编辑，保存 .dwxml / .dwxmz、预览、物流表及工况结果。物性、模型与参考数据仍需逐项核对；动态仿真、动力学 CSTR/PFR 和任意代码速率不在本版范围。

升级会影响已有工程数据吗？+

升级前关闭使用 ChemELLM 的会话，备份安装目录下的 data 与 .chem，再将新版完整覆盖到原目录并运行 INSTALL.cmd。旧项目保留原流程，迁移到新流程需显式操作并核对；新会话加载新版。安装后保留整个目录，移动后需重新生成连接配置。

计算结果可以直接用于工程设计吗？+

需要根据模型适用范围、输入条件与依据进行专业审核。ChemELLM 保存自动校核结果，但自动校核不代表工程标准符合性或专业审核通过。
