BUILT FOR ENGINEERING

不止一次回答，
更是一套工程工作流。

把分散的计算、资料和文件放回同一个项目。
让后续复算、修改与交接，都有迹可循。

01 / COMPUTEƒ

真实计算，保留每个条件

调用 CoolProp、thermo 等计算工具，开展物性、热力学与工程计算。输入、结果、单位及适用条件一起保存。

物性计算 · 工程计算 · 单位换算
02 / SIMULATE⇄

从稳态求解，到工况比较

接入本机 DWSIM，检查模型、运行多工况并独立校核守恒。保留原生流程，将选定结果关联到工程对象。

建模检查 · 多工况比较 · 设计联动
03 / REFERENCE≡

资料可复用，引用可回看

归档标准、手册和参考资料，保留原件与来源。图像按页码和区域定位，项目引用固定版本，随成果包保存副本。

本地资料库 · 版本记录 · 项目引用
04 / ESTIMATE¥

让每一笔价格有来路

管理设备、原料与能源价格，区分真实报价和假设估值，保留适用条件、修改理由与变更历史。

价格台账 · 来源记录 · 历史追踪
05 / DELIVER↗

交付成果，也交付过程

生成报告、数据表与工程文件，将计算记录、固定版本的引用和源文件一并打包，用 SHA256 核对交付内容。

报告与数据表 · 原生文件 · 成果打包
06 / LOCAL FIRST⌂

工程空间，就在本地

项目与成果保存在你的电脑中。所需外部软件按任务接入，缺少工具时说明安装方案，经你同意后安装。

本地存储 · 按需安装 · 自主保留

DWSIM / STEADY-STATE

从一个稳态流程，
到一组有依据的工况。

稳态仿真与原生布局

让仿真进入工程流程。
模型、校核、比较和设计量，都保留来路。

01 CHECK

求解之前，先检查模型

检查进料、连接、端口与已支持的规格，定位缺项和冲突；支持原生流程自动分区及局部布局编辑，另存模型与预览。

保留原始输入与检查记录
02 VALIDATE

收敛之后，独立核对守恒

对单元及全流程独立核对质量、组分和能量，反应过程另核对元素；缺少必要信息时保留待核对状态。

求解状态与校核结果分别保存
03 COMPARE

固定基准，比较多个工况

串行运行最多 50 个工况，支持进度查看、取消与续算，输出 CSV、JSON 和图表；失败点不进入有效包络。

每个工况保留独立模型与结果
04 CONNECT

选定结果，联动工程设计

将校核通过的选定结果按明确单位和版本映射到工程对象，追踪计算来源，继续生成设备数据表。

操作条件与机械设计条件分别记录

面向 Windows / DWSIM 稳态流程，需单独安装 DWSIM。动态仿真与动力学 CSTR/PFR 不在当前支持范围。

GOOD TO KNOW

开始之前，
你可能想了解。

这是在线计算网站吗？+

这里是产品介绍与下载网站。ChemELLM 安装在本地，通过 Codex 调用工程工具；项目、计算记录与成果保存在安装目录中。

本地保存，是否意味着完全离线？+

项目数据保存在本地；Codex 的模型连接遵循你所使用的服务和设置。首次安装、在线资料获取及外部软件安装需要网络。本地存储不等于所有任务都离线执行。

安装包包含哪些专业软件？+

安装器准备基础 Python 计算依赖。DWSIM、Blender、FreeCAD、LibreOffice 和 Cantera 等按需单独安装，不随 ZIP 分发。DWSIM 接入目前面向 Windows 稳态仿真，复杂模型需要另行配置与验证。

v0.6.0 的流程仿真能做什么？+

支持建模前检查、稳态求解、独立守恒校核、最多 50 个工况的串行比较和工程对象联动，支持原生布局编辑，保存 .dwxml / .dwxmz、预览、物流表及工况结果。物性、模型与参考数据仍需逐项核对；动态仿真、动力学 CSTR/PFR 和任意代码速率不在本版范围。

升级会影响已有工程数据吗？+

升级前关闭使用 ChemELLM 的会话，备份安装目录下的 data 与 .chem，再将新版完整覆盖到原目录并运行 INSTALL.cmd。旧项目保留原流程，迁移到新流程需显式操作并核对；新会话加载新版。安装后保留整个目录，移动后需重新生成连接配置。

计算结果可以直接用于工程设计吗？+

需要根据模型适用范围、输入条件与依据进行专业审核。ChemELLM 保存自动校核结果，但自动校核不代表工程标准符合性或专业审核通过。
