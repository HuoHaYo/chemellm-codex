GOOD TO KNOW

开始之前，
你可能想了解。

这是在线计算网站吗？+

这里是产品介绍与下载网站。ChemELLM 安装在本地，通过 Codex 调用工程工具；项目、计算记录与成果保存在安装目录中。

本地保存，是否意味着完全离线？+

项目数据保存在本地；Codex 的模型连接遵循你所使用的服务和设置。首次安装、在线资料获取及外部软件安装需要网络。本地存储不等于所有任务都离线执行。

安装包包含哪些专业软件？+

安装器准备基础 Python 计算依赖。DWSIM、FreeCAD、LibreOffice 和 Cantera 等按需单独安装，不随 ZIP 分发。DWSIM 接入目前面向 Windows 稳态仿真，复杂模型需要另行配置与验证。

升级会影响已有工程数据吗？+

升级前关闭使用 ChemELLM 的会话，备份安装目录下的 data 与 .chem，再将新版完整覆盖到原目录并运行 INSTALL.cmd。安装后保留整个目录，移动目录后需要重新生成连接配置。

计算结果可以直接用于工程设计吗？+

需要根据模型适用范围、输入条件与依据进行专业审核。ChemELLM 保存自动校核结果，但自动校核不代表工程标准符合性或专业审核通过。
