# ChemELLM Codex v0.4.0

增加 DWSIM 稳态流程仿真、按需工具安装、可编辑价格台账和共享参考资料库，继续提供 Windows x64 一键联网安装包。

## 安装与升级

1. 下载本页附件 **ChemELLM-Codex-0.4.0-windows-x64.zip**，完整解压到长期保留的可写目录。
2. 双击 **INSTALL.cmd**，准备独立 Python 3.12、安装锁定依赖、检查真实 MCP 启动并注册插件。
3. 看到 `Installed successfully` 后重启 Codex、新建会话。双击 **CHECK.cmd** 可再次检查环境。

需先安装并登录支持插件的 Codex。无需自行安装 Python 或 Git；首次安装需联网访问 GitHub 和 PyPI。升级前关闭使用插件的会话并备份 `data/` 与 `.chem/`，将新版完整覆盖到原安装目录，再运行 `INSTALL.cmd`。保留整个安装目录，启动配置使用绝对路径。

## 本版变化

- **DWSIM 稳态仿真**：查询真实组分和物性包，创建或载入流程，检查属性和单位，更新工况并求解；保存输入原件、完整结果、物流表和原生 `.dwxmz`。未收敛结果保留失败状态，不能用作通过校核的设计值。
- **按需安装外部工具**：检测 DWSIM、FreeCAD、LibreOffice、Cantera，为当前任务生成安装方案；用户明确同意后才启动安装，记录进度并验证接口。检测与准备方案不会安装软件。
- **可编辑价格台账**：保存设备、原料、能源及其他费用，保留来源、适用条件和变更历史；区分真实报价与假设估值，防止估值覆盖实价，支持本地编辑与版本冲突处理。
- **共享参考资料库**：归档原件和来源，索引长文档，分别保存逐字转录与整理稿；可编辑、检索并追踪历史，项目引用固定版本，随成果包保留独立副本。
- **安装代理修复**：Windows PowerShell 5.1 的首次引导下载支持显式 `HTTPS_PROXY`，沿用 SHA256 校验。

DWSIM、FreeCAD、LibreOffice 和 Cantera 不随 ZIP 分发。DWSIM 需 Windows 版外部安装，本版接入稳态求解；动态、反应集及复杂模型需另行配置和验证。基础安装使用固定版本及哈希的依赖，不安装全部可选工程工具。

ZIP 附带逐文件 SHA256 清单，另提供 **SHA256SUMS.txt**。数值保留单位、条件和来源；自动校核不等于专业审核。

发布验证：40 项测试通过，包括真实 DWSIM 计算和 stdio MCP 协议测试；中文及空格路径中的全新安装、28 个 MCP 工具发现、插件缓存启动、重复安装保留数据和依赖兼容性检查通过。
