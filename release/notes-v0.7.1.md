# ChemELLM Codex v0.7.1

此补丁版更新官网的工具介绍和排版。插件的计算、制图和仿真功能与 v0.7.0 相同，已安装 v0.7.0 的用户可以继续使用。

- 首页「连接熟悉的工程能力」补充 QElectroTech（仪表与电气接线）和 Vega-Lite（科研绘图）。
- 工具列表在窄屏上自动分行，黑白主题均沿用统一的工具名与用途样式。

Windows x64 用户可下载 `ChemELLM-Codex-0.7.1-windows-x64.zip`，完整解压后运行 `INSTALL.cmd`。下载后可用 `SHA256SUMS.txt` 校验。安装完成后开启新的 Codex 会话。
