# ChemELLM Codex v0.5.0

DWSIM 稳态流程新增建模前检查、独立守恒校核、多工况比较和工程对象联动；官网同步提供新版 Windows x64 安装包。

## 安装与升级

下载 **ChemELLM-Codex-0.5.0-windows-x64.zip**，完整解压到长期保留的可写目录，双击 **INSTALL.cmd**。安装器准备独立 Python 3.12、安装锁定依赖、检查 MCP 并注册插件；完成后重启 Codex 并新建会话。需先安装支持插件的 Codex，首次安装需联网访问 GitHub 和 PyPI。

升级前关闭插件会话并备份 `data/` 与 `.chem/`，将新版完整覆盖到原安装目录，再运行 `INSTALL.cmd`。专业外部软件按需安装，不随 ZIP 分发。

## 本版变化

- **建模前检查与校核**：`check` 检查进料、连接、端口和规格；独立核对质量、组分、能量，反应过程另核对元素衡算。缺失信息保留待核对状态。
- **结构化稳态模型**：增加物性包及二元参数来源记录、泵和压缩机、阀、冷热设备、闪蒸、简捷塔与严格塔、循环初始化、转化率及平衡反应配置。
- **多工况比较**：新增 `chem_dwsim_study`，固定基准模型运行最多 50 个工况，支持进度、取消及续算，导出 CSV/JSON/PNG；失败和校核不完整的点不进入设计包络。
- **设计联动**：新增 `chem_dwsim_publish`，通过显式结果路径、单位换算及版本检查更新工程对象，记录计算来源与参考值；操作条件与机械设计条件分别保存。
- **官网与隐私**：公开官网源码及部署流程，更新下载至 v0.5.0；移除源码来源记录中的本机用户绝对路径。旧提交和旧发布附件仍可能保留历史信息。
- **解压后运行器识别**：使用源码与 EXE 的内容指纹判断是否需要重建，修复解压时间导致 DWSIM 被误判为不可用的问题。

支持范围为 Windows / DWSIM 稳态流程；动态仿真、动力学 CSTR/PFR、任意代码速率及通用自由度分析不在本版范围。自动校核与独立参考比较不能代替专业工程审核。

附件包含逐文件哈希清单，另附 **SHA256SUMS.txt**。官网：[chemellm.online](https://chemellm.online/)。

发布前已在独立 CPython 3.12.15 环境验证内核、真实 stdio MCP、真实 DWSIM 稳态扩展、工况恢复和依赖流程；隔离 Codex 插件缓存启动发现 30 个工具。安装验证复用本仓库旧版测试的 Python 和依赖下载缓存，新虚拟环境不继承系统包；本次未完成无缓存联网下载验证。验证细节见 `docs/releasing.md`。
