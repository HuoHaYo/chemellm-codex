# ChemELLM Codex v0.6.0

新增依据选择、项目流程与成果采集能力，支持 Blender 厂区三维演示。

- 一次初始化即可探索试算，正式交付按采用计算、设计依据和成果版本审核。
- 数值按用户数据、适用资料或推算、合理假设的顺序选取，保留单位、候选与假设传递。
- 来源组与批量简写去除重复说明；固定 2,500 参数测试提交量减少 98.80%。
- Blender 后台生成设备、管道、管廊和建筑，输出 blend、GLB 与 PNG；CAD 外观导入另需 FreeCAD，三维演示不替代工程审核。
- DWSIM 原生布局支持自动分区与位置、尺寸、方向编辑，另存 DWXML/DWXMZ 和预览；布局操作不执行求解。
- 外部 blend、GLB、网页及资源批量固定版本登记，保持相对路径和文件哈希；外部报告结论明确标明来源。
- SQLite 项目状态、分页详情与增量快照；后台日志进入 stderr，状态与取消无需等待求解结束。
- 图像引用固定页码/区域及哈希，整理稿按需生成；价格、单位、用户数据优先级和假设传递保持回归覆盖。
- 旧项目保留原流程；仅显式迁移，升级前备份并核对，失败恢复旧项目。

安装更新后在新会话生效；原油表征与收敛算法未在本轮调整。实现、测试边界和迁移步骤见 `docs/efficiency-v2.md`。
