# 工程图纸与三维表达

只在出图、布置、模型或视觉审核时读本文件。按用户任务书确定深度；探索阶段可先做局部图，不要求每次试画建立全套台账。

## 依据分层

先查任务书、当届专项评审、适用标准，再参考公开作品。获奖新闻或渲染图只能作表达参考，不能证明工艺正确或标准符合。标准号、版本、状态、适用范围与实际读过的页/条分开记录；只取得题录不能写“已按全文核对”。

2026 苯乙烯赛题的公开材料入口：[高校通知与附件](https://www.nxxhxy.com/gcyyykxx/content?id=6003234)。以下具体数值来自其[工程图纸质量评审细则](https://www.nxxhxy.com/static/upload/18f8a712-2fdd-4804-b630-d49d52618aa7.pdf)第1—5页，属于该届评审要求；不把转引片段当作已读标准全文。

## 图纸

| 图种 | 应能直接读到的信息 |
| --- | --- |
| PFD | 设备位号/职责、完整进出物流与箭头、物流号，以及对应温度、压力、流量、组成、相态；与采用衡算一致 |
| P&ID | 同一工艺拓扑、管道组合号、规格/等级/保温、阀门与测点、控制逻辑及保护动作；信号线不当作电气接线 |
| 车间平立面 | 相同轴线和坐标基准、设备位号及定位尺寸、标高、楼层/平台、重要配管、操作检修与疏散通道 |
| 总图 | 北向/真实来源的风玫瑰、场地坐标与尺寸、分区、建筑/占地指标、物流人流、消防与事故水设施；间距依据另核 |
| 设备条件图 | 外形/关键内件、接管表及方位/标高、介质与设计/操作条件；计算给不出的接口标待定 |

该届图纸一般用 A1，内容少用 A2；车间常用 1:100（可选1:50/1:200），总图常用1:500（可选1:200/1:1000）。PFD/P&ID标“不按比例”，不能从示意图量施工尺寸。图框、项目名、队名、图号、版本、单位和真实设计/校核身份应齐；没有实际人员签署时留待审核，不编造签名。

纸面线宽：主物料线0.8 mm，其他物料线0.4 mm，设备轮廓0.25 mm。细则第2页推荐图名7 mm、工程名/说明/轴号5 mm、数字字母2—3 mm；表格文字一般5 mm、格高小于6 mm时3 mm，标题栏与PFD物流表另有放宽。拥挤时拆图/续表，不靠缩成微字、裁掉数值或删设备解决。

`pid`生成器的`edges[].line_role`可为`main`（默认）或`secondary`，分别用0.8/0.4 mm；默认仅是绘图层级选择，按实际用途确认。设备轮廓为0.25 mm。仪表信号虚线、联锁点划线是当前模板约定，不代表已区分所有信号介质或已逐符号核对ISA标准；保留图例并按适用仪表标准核对。

生成后同时看PDF/SVG与原生CAD：同一连接的线型、线宽、箭头、位号和字形应一致，黑白打印仍可分辨。当前标准模板DXF为AC1018、毫米纸面；PDF可读不能证明`gbcbig.shx`在CAD中正确显示。原生字体仍需实机验证。当前模板字高/密度、交叉连接表示和长表续页尚未全面自动化；`passed`只代表已执行的检查。

## 三维

沿用计算、图纸和模型的同一设备ID、职责、坐标与版本。核对“物流→设备职责→接管→路由”，仅检查ID存在不够。例如产品冷却器不能因为外形相同而误接轻组分冷却器。

`export_blender`管道用连续封闭网格和相切圆弧。`bend_radius`为中心线半径，与`units`同单位，必须大于外半径；未填时1.5D仅为明确记录的展示假设。空间不足/折返会拒绝生成，调整真实路由或明确半径，不能跳过失败。封闭连通只证明单条管道网格；不同管道、设备接管、全局自交、碰撞、保温及支撑仍需检查。

至少看总览、关键转角/接管近景，以及与平立面相同视向；设备ID、坐标轴/方向、单位和必要图例应可辨。展示材质不冒充介质/安全色规定。模型应表达约定的重要管道、并联集分配管、平台梯子和检修包络；不要用漂亮渲染替代这些内容。

该届[现代设计方法细则](https://www.nxxhxy.com/static/upload/40f26aaf-093c-4e20-9e68-0fbdc7abc507.pdf)第8页考察数据库驱动型专业软件及三维与平立面吻合。Blender展示网格或自定义ID不等于已经满足该软件条件；应提前说明差距并选择实际满足任务的软件与数据链。

## 交付与存储

单一正式成果源，按交付项引用固定版本；不为每轮展示全量复制工程。QA渲染、解包验证和可再生网格放临时目录，保留必要摘要；`.blend1`、工作脚本和诊断不进最终包。资料原件和采用结果的证据继续内部保留。旧版本删除/回收另走有引用核对的清理流程，不因本规则删除已有项目。
