## 标准身份与规则边界

在国家标准官方平台核对了以下题录及查询日的“现行”状态，**没有把题录核实升级为全文合规审查**：

| 标准 | 用途 |
| --- | --- |
| GB/T 14689-2008 | 图纸幅面和格式 |
| GB/T 14690-1993 | 制图比例 |
| GB/T 14691-1993 | 制图字体 |
| GB/T 4457.4-2002 | 机械制图图线；不能单独代替P&ID仪表表示标准 |
| GB/T 6567.2-2008 | 管路系统的图形符号：管路 |
| GB/T 10609.1-2008 | 标题栏 |

官方目录链接见来源索引。HG/T 20519-2009的线宽、字高及管道组合号要求，本次是在工程图纸评审细则的转引处读取；没有取得其完整标准原文。HG/T 20505、HG/T 20688、ISO 10628、ISA-5.1的版本/全文配对继续待办。总图防火规则还需按适用范围核对GB 55037、GB 50160、GB 50016、SH/T 3196等原文及修订关系，不预置一个“全厂通用安全间距”。

可执行规则集中于[技能共享参考](../codex-plugin/skills/chemellm-engineering/references/visual-standards.md)，仅相关任务加载：图种深度、纸面线宽/字高、坐标/尺寸/标高、真实字体、设备职责、接管与路由、总览及局部检查。

**特别发现：**现代设计方法细则第8页明确考察数据库驱动型专业软件。当前Blender演示网格、自定义位号及连通检查不能直接证明满足该条件；专业软件与对象数据库链路单独列入待办。

## 本批源码改进

- `app/pipe_geometry.py`生成相切圆弧与连续圆截面网格，平行传递截面方向，起终点封口；不再逐段摆放互不连通的圆柱。支持显式中心线半径，默认1.5D标为展示假设。拒绝零长、直接折返、外半径以上条件不满足及相邻弯头放不下的路径，不静默压缩弯头。
- Blender实测封闭流形及连通分量数，报告保存半径选择、局部端点、单位与未审核范围。固定几何代码随内部复算资料冻结。网格连通不等于设备接管匹配或全局不自交。
- DXF导出保留虚线、点划线及纸面线宽；标准P&ID DXF采用AutoCAD 2004/AC1018和毫米单位。主物料/其他物料线分别0.8/0.4 mm，设备轮廓0.25 mm；通过`line_role`选择，图例同步。
- 自动提示单张管线表8行上限、缺少队名/业主、设计和校核同名；返回实际视觉检查范围。当前字高/密度、续表、碰撞及专业控制逻辑未宣布通过。
- 公共/三维技能引用同一份详细规则，避免五个技能重复加载。现有项目及成果ID继续复用。
