# DWSIM 稳态扩展验收记录

本次在 Windows、本机 DWSIM 9.0.5 下验收；使用当前仓库的独立临时项目与真实 Automation3 子进程。没有新增模型 API、动态仿真或动力学速率表达式。调用字段及完整示例见[调用说明](../codex-plugin/skills/chemellm-engineering/references/dwsim.md)。

| 步骤 | 已实现与验收依据 |
| --- | --- |
| 1 建模前检查 | 新建及载入修改的 check；明确进料缺项、连接/端口、已支持规格及冲突定位到位号；不求解、不新增正式计算、原文件哈希不变；未知来源及未实现自由度判断保留待核对 |
| 2 独立守恒 | 单元及外边界质量、组分、能量；含内部循环、热流和轴功；解析混合器及人为篡改结果，缺失数据为null；水加热负荷另与CoolProp焓差对比 |
| 3 物性与参数 | 水/蒸汽、PR烃类、NRTL；按单元绑定；二元参数与来源、条件、方向、温度形式保存/重载；用户覆盖与原生数据库/默认值、缺失值区分 |
| 4 热工分离 | 真实泵、压缩机、阀、冷却器、两相闪蒸、UA换热器、简捷塔和严格塔；保存重载；泵功率与密度、换热器有效度、闪蒸K值另有独立预期；严格塔稳定基准塔顶苯摩尔分数约0.9693 |
| 5 循环与诊断 | 分流—循环解析预期：外出流量等于进料；显式初值、初始化步骤、容差/迭代上限；严格设置产生真实不收敛，保留原生模型与实际错误和残差 |
| 6 多工况 | 命名工况、实际温度扫描；固定基准、逐工况原生模型和计算；部分失败保留、取消/续算、进度、CSV/JSON/PNG；只有校核及指标完整的点进入包络；中断恢复另有确定性状态机测试 |
| 7 反应 | 30%转化率解析案例、WGS平衡案例；组分与配平校验；元素和含生成焓能量衡算；WGS在1000K的气相平衡常数与NIST参考点约1.435比较 |
| 8 设计联动 | 显式路径和单位换算；校核失败/不足及无当前校核版本的旧记录拒绝发布；重复发布不重复对象，版本冲突409；机械设计条件独立；数据表JSON/DOCX/PDF固定工程对象版本及来源，文件哈希验证 |

独立参考不等于专业审核。闪蒸相平衡K值对比允许不同蒸气压关联式的3%差异，不声称汽化率有同等相对精度；原生数据库参数的来源和适用范围仍可能待核对。WGS比较使用[NIST WebBook](https://webbook.nist.gov/chemistry/)理想气相热化学参考点并容许低压PR非理想性差异，不能替代工厂实测验证。其他体系、参数和DWSIM版本须另行验证。

原生模型、原始资料、运行日志、项目与SQLite均保存在忽略的数据目录；源码中的合成请求可随插件分发。没有修改旧计算的校核结论；发布要求新的 `validation.schema_version=1`。动态、动力学CSTR/PFR、任意代码速率和通用自由度分析不在本版范围。
