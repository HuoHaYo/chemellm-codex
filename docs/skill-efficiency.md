# 技能与工具提效验证

2026-11-11，开发源码验证；运行中的用户插件缓存未更新。工程数据继续使用 `cpc/chemellm-data`，测试全部采用独立临时目录。

## 结构与兼容

同一个 MCP 保留 34 个工具。公共入口 `chemellm-engineering` 与 DWSIM、三维、资料、费用四个专项可直接使用，共享项目和成果 ID。公共正文 1,400 字节，专业正文 1,064–1,773 字节，详细操作和设备示例按需读取。旧参考路径保留转向入口。

`chem_tools` 新增摘要分类分页，指定工具时不生成其他 schema；`chem_calculations` 新增目录摘要及结果字段读取。未指定新模式的调用与 full 保持兼容。摘要中的 recorded 仅说明记录存在；选择读取保留结果哈希和分页位置，过大字段返回提示而非截断原值。所选计算按当前项目检查归属，读取不新增计算、运行或版本历史。

公共技能指纹字段继续保留；新增 `skillSetFingerprint`、`skillSetPairing` 及逐技能指纹。配置固定期望值，不在启动时自动替换。配置重新生成保留未显式指定的工程存储及允许目录。安装检查区分源码验证和实际缓存验证；发行清单包含整包与逐技能指纹。

## 技能选择边界评审

以下为入口和资源安排的静态行为评审，不冒充已在用户新会话测量的自动选择结果：

| 请求场景 | 应使用的技能 | 关键行为 |
| --- | --- | --- |
| 水物性、换热或单位换算 | engineering | 直接查已知工具，初始化一次后试算 |
| DWSIM 泵或闪蒸模型 | dwsim | 专项入口＋基础主题＋单个设备示例 |
| Blender 厂区或 CAD 设备 | 3d | 看实际预览，区分展示几何和工艺依据 |
| 工程标准图表引用 | references | 原件、相关页、固定引用；文字引句才转录 |
| 设备报价及成本评价 | costing | 稳定价格 key，读取版本，实价保护 |
| 标准取值后 DWSIM 建模 | references＋dwsim | 同项目复用引用和依据，不重复初始化 |
| 仿真成果用于三维展示 | dwsim＋3d | 复用成果 ID，按需要关联展示资源 |
| 设备选型与投资报告 | engineering＋costing | 复用设备和计算，采用结果后统一交付 |
| 普通非工程 PDF 阅读 | 无 ChemELLM 技能 | 不启动工程资料库 |
| 普通网站或插图制作 | 无 ChemELLM 技能 | 不启动工程项目 |

实际自然语言自动选择仍由 Codex 客户端与模型决定。当前会话保留旧缓存；统一刷新后，应在新的用户会话逐项核对触发及混合任务行为，再记录真实读取量。安装成功和静态评审不等于已完成该自动选择验收。

## 更新步骤

先运行回归、五技能验证及 `check-installation.py --source-only`。在不打断正在建模的会话时统一刷新插件，随后运行实际缓存检查并在新会话读取 health。整包必须 matched；旧配置可启动但明确显示 unconfigured。数据位置以 health 为准，重新生成配置不得将工程数据切回开发目录。无需迁移项目、清理历史、运行全部审核或打包。
